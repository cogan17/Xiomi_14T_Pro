Mode

🌡️ Suhu & CPU
--
🧯 Rem HyperOS

Baca saja: batas yang dipasang HyperOS sendiri (thermal_message). Modul tidak mengubahnya. Suhu papan HyperOS juga dicatat di tab Suhu sebagai sensor hyperos_board (Badan HP).

🔌 Cas
--

Bawaan: mati. Suhu cas diatur sistem HP (HyperCharge). Nyalakan untuk jeda tambahan dari modul: cas dijeda bila baterai terlalu panas atau, di Kernel Default, bila cas membuat Badan HP panas; lanjut setelah turun 3 °C.

colokkan charger dulu

Pencarian saklar mematikan dan menyalakan cas sebentar. Jika saklar sudah ditemukan, tidak perlu mencari ulang saat HyperCharge berjalan.

⚙️ Setelan mode

Ambang mode dibaca dari suhu Badan HP (yang terasa di tangan). Hemat 2 °C di bawah Kernel Default. Langkah halus: mulai 1 °C sebelum ambang, CPU besar turun 10% per langkah sampai 60%, CPU kecil (yang menjaga UI tetap lancar) paling akhir dan tidak di bawah 80%. CPU hanya diturunkan saat prosesor bekerja (≥ 60 °C); panas dari cas atau ruangan tidak membuat CPU diturunkan. Di semua mode ada rem darurat bila prosesor ≥ 95 °C.

Simpan: simpan setelan (pengendali aktif membaca pada interval berikutnya). Paksa: simpan, mulai, terapkan sekarang dan ulangi tiap interval. Henti dan Reset melepaskan kontrol milik modul. Reset memakai cas 95/90 dan berhenti sampai Mulai.
