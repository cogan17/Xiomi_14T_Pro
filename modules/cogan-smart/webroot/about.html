👋 Tentang kami

👋 About us

Cogan17 membangun kernel kustom Cogan Rothko untuk Xiaomi 14T Pro: sumber kernel bawaan HP (Android Common Kernel 6.1) ditambah KernelSU Next, SUSFS, NoMount, BBRv3 dan Cogan Bridge, driver kecil yang membuat kernel dan modul ini saling mengenal. Setiap build diperiksa otomatis terhadap ABI kernel bawaan sebelum diuji di HP sungguhan.

Cogan17 builds the custom Cogan Rothko kernel for the Xiaomi 14T Pro: the phone's own kernel source (Android Common Kernel 6.1) plus KernelSU Next, SUSFS, NoMount, BBRv3 and Cogan Bridge, a small driver that lets the kernel and this module recognise each other. Every build is checked automatically against the stock kernel ABI before it is tested on a real phone.

Modul ini adalah "otak" kernel: kebijakan ada di sini, kernel menyediakan sensor dan tuas. Proyek saudara: TWRP Xiaomi 14T Pro.

This module is the kernel's "brain": the policy lives here, the kernel provides the sensors and knobs. Sister project: TWRP Xiaomi 14T Pro.

🔏 Authenticity

Kode modul terbuka di repo cogan17/Cogan-Kernel (folder modules/cogan-smart). ZIP-nya dibuat dengan scripts/package_module.py yang selalu menghasilkan berkas sama persis dari kode yang sama, jadi siapa pun bisa membangun ulang dan mencocokkan SHA-256 ZIP yang diterimanya.

The module's code is open in cogan17/Cogan-Kernel (folder modules/cogan-smart). Its ZIP is made by scripts/package_module.py, which always produces the identical file from the same code, so anyone can rebuild it and compare the SHA-256 of the ZIP they received.
